## 2024-05-19 - Global Tooltip Configuration in Radix UI
**Learning:** Radix UI's `Tooltip` components require a `TooltipProvider` to function properly, particularly for features like global delays. When wrapping individual interactive elements with tooltips, it is crucial to ensure they are nested within a single `TooltipProvider` (typically at the root layout level) rather than giving each tooltip its own provider. Also, to prevent invalid HTML nesting, `<TooltipTrigger asChild>` should be used when wrapping existing buttons.
**Action:** Always verify that `<TooltipProvider delayDuration={300}>` is configured in `app/layout.tsx`. Use `<TooltipTrigger asChild>` around existing accessible interactive elements to preserve proper DOM structure and accessible properties. Include `<TooltipProvider>` in any component tests that render tooltips.
