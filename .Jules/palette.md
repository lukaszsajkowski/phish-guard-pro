## 2024-05-24 - Dynamic Accessible Tooltips
**Learning:** For dynamic icon-only buttons (like a Copy button changing to a Copied! checkmark), static `aria-label` or `title` attributes aren't sufficient since they don't reflect state changes. Screen readers need `aria-live="polite"` with visually hidden dynamic text (`<span className="sr-only">`). Also, adding Radix UI tooltips globally using `TooltipProvider` at the root layout prevents testing timeouts and context errors, and `asChild` must be used on `TooltipTrigger` when wrapping existing interactive elements like buttons.
**Action:** Always use `aria-live` and a visually hidden span for dynamic icon button states. Always wrap test files utilizing tooltip components with `<TooltipProvider delayDuration={0}>` to prevent test timeouts.
