## 2026-06-20 - Wrap Tooltips for Icon Buttons
**Learning:** Icon-only buttons often lack accessible labels or tooltips, which makes it harder for users to understand what the button does. While native HTML `title` tags are an option, they don't look great and can be slow to appear. Wrapping icon buttons in a `Tooltip` component provides a much better and immediate user experience.
**Action:** When adding or discovering icon-only buttons, prioritize wrapping them in a `Tooltip` component (from the UI library, like Radix UI) to ensure accessibility and better visual feedback.
