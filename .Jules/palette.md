## 2024-07-15 - Accessible Expand/Collapse Toggles
**Learning:** For accessibility in the frontend, expand/collapse toggle buttons must implement `aria-expanded` and `aria-controls` attributes, and the target content container must have a matching `id`. Relying solely on visual cues (like chevron changes or text changes like "Show more/Show less") is insufficient for screen readers. Using React's `useId()` hook to generate unique IDs is a robust way to prevent collisions when there are multiple collapsible components on the same page.
**Action:** When creating or modifying expand/collapse functionality, always ensure `aria-expanded` reflects the current state, dynamically link the toggle to its content using `useId()` for `aria-controls` and `id`, and update associated tests to verify these dynamic attributes.
