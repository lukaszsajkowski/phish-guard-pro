## 2025-07-23 - Adding Tooltips to Icon-Only Buttons
**Learning:** Using `aria-label` alone is insufficient for icon-only buttons because it doesn't provide visual feedback for sighted users. Native `title` attributes are often used as a fallback, but they have inconsistent delays and poor styling. Radix UI Tooltips provide a more accessible and visually consistent alternative. To ensure a consistent delay across all tooltips in the application, a global `<TooltipProvider delayDuration={...}>` should wrap the root layout instead of wrapping individual `<Tooltip>` elements. Also, when writing Vitest tests using `@testing-library/react` and Radix tooltips, you must manually trigger user interactions (e.g., `userEvent.hover()`) and query for the tooltip text after waiting for it to appear, rather than checking the native `title` attribute.
**Action:** Always wrap icon-only buttons in a Radix `<Tooltip>`. Ensure the application has a global `<TooltipProvider>` configured, and use `<TooltipTrigger asChild>` to prevent invalid HTML nesting (button inside button). When testing tooltips, use `userEvent.hover()` and `waitFor` to assert the tooltip's presence correctly.
