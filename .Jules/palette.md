## 2024-03-20 - Dynamic Text Accessibility
**Learning:** When using `aria-live="polite"` on an element with dynamic text (like a copy button), standard frontend testing assertions like `toBeInTheDocument()` are insufficient for testing accessibility correctness; update the test to explicitly verify `toHaveAttribute('aria-live', 'polite')`. Also, do not add static `aria-label` attributes to buttons whose visible inner text changes dynamically (e.g., 'Copy' -> 'Copied!'), as the static label overrides the state change. Instead, use `aria-live="polite"` to ensure screen readers announce the dynamic text changes.
**Action:** Remove static `aria-label` and add `aria-live="polite"` for buttons with dynamic text, and update tests to explicitly check for the `aria-live` attribute.
