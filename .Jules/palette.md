## 2024-03-24 - Dynamic text accessibility in copy buttons
**Learning:** When using `aria-live="polite"` on a button where the text changes dynamically (e.g., from "Copy to clipboard" to "Copied!"), if the dynamic text is rendered in a `<span className="sr-only">`, any accompanying visible text or icons need to be hidden from screen readers using `aria-hidden="true"` to prevent duplicate announcements. Also, standard frontend testing assertions like `toBeInTheDocument()` may fail or be insufficient if the test suite isn't prepared for `aria-live` or duplicate screen reader nodes.
**Action:** Always wrap the dynamically changing text in a visually hidden span for screen readers, hide the visual representation with `aria-hidden="true"`, and ensure the button container has `aria-live="polite"`. Add to standard accessibility checklists for interactive buttons.
