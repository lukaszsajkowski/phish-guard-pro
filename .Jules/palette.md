## 2024-11-03 - Accessible dynamic copy buttons\n**Learning:** When using copy buttons that change their text/icon to indicate a successful copy, a static aria-label will hide this state change from screen readers. Screen reader users need to be notified when the state changes to 'Copied!'.\n**Action:** Use `aria-live="polite"` on the button and a visually hidden `span` (like `<span className="sr-only">`) containing the dynamically updating text instead of a static `aria-label`.
