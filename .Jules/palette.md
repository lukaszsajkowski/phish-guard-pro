## 2024-05-15 - Tooltips for Icon-Only Buttons
**Learning:** While native HTML `title` and `aria-label` attributes provide basic accessibility, custom tooltips offer a superior user experience, especially for interactive elements without visible text. Implementing tooltips using Radix UI requires a global `TooltipProvider` at the layout root to support features like shared delay semantics. Furthermore, when testing components wrapped in custom tooltips, RTL's `userEvent.hover()` alongside a `delayDuration={0}` on a surrounding `TooltipProvider` is crucial for avoiding test timeouts and ensuring elements are portaled and rendered correctly before querying.
**Action:** When adding tooltips to icon-only buttons, ensure a `TooltipProvider` is present at the application root (e.g., `layout.tsx`). In test environments, always wrap the tested component with `<TooltipProvider delayDuration={0}>` to facilitate instantaneous hover testing with `userEvent` and `waitFor`.
