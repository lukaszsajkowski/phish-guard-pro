## 2024-07-03 - Expand/Collapse Toggles Accessibility
**Learning:** Found multiple toggle buttons (e.g., "Details" for risk breakdowns, "Show raw data" for enrichment results, "View all" for timelines) in `IntelDashboard.tsx` that relied solely on visual cues (like text changes or chevrons) or simple conditional rendering to convey state changes. Screen readers need explicit attributes like `aria-expanded` and `aria-controls` to understand when a button expands or collapses content. Additionally, `aria-controls` must point to an exact matching `id` on the target container. Because components like dashboards often render multiple lists of similar items, hardcoding IDs can cause collisions.
**Action:** When creating or updating expand/collapse functionality in React, always add `aria-expanded={isExpanded}` and `aria-controls={id}` to the trigger button, and `<div id={id}>` to the content wrapper. Use React's `useId()` hook to generate unique prefixes for these IDs (e.g., `aria-controls={\`\${idPrefix}-raw-data-\${key}\`}`) to ensure uniqueness across repeated maps or loops.
