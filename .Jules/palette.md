## 2024-08-11 - Add aria-live for dynamic copy status\n**Learning:** When text inside a button changes dynamically (e.g., 'Copy' -> 'Copied!'), screen readers might not announce the change if aria-live is missing or if static aria-labels are present, overriding inner text.\n**Action:** For dynamically changing text without overriding aria-labels, use aria-live="polite" on the container, or use an announcement div.
