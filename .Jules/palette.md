## 2024-08-01 - Tooltips > Native Titles
**Learning:** Native HTML `title` attributes are inconsistently supported (especially on mobile/touch screens) and cannot be customized for visual accessibility or delay. Radix UI Tooltip components provide a more robust, accessible alternative for conveying information on hover (especially for icon-only buttons).
**Action:** When adding accessible tooltips to existing interactive elements using Radix UI Tooltips, the `<TooltipProvider>` must be explicitly provided in the app layout and within component test renders (`IntelDashboardEnrichment.test.tsx` needed it to avoid rendering crashes). Additionally, use `userEvent.hover()` and query by `role="tooltip"` to assert tooltip presence in tests instead of checking for `title` attributes.
